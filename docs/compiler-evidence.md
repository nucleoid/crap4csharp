# Actual compiler evidence

The private adapter executes one selected-SDK, nonincremental, no-restore build of a mapped graph node with all mapped global properties. It explicitly disables reference rebuilding; callers must provide dependency-first prepared graph outputs. It disables shared compiler execution so the invocation does not depend on a long-lived compiler server. Public fresh `check` uses this adapter through the phase-bound graph scheduler, then independently executes and binds required tests and coverage. Compiler evidence alone never establishes public completion; see [fresh check](check.md).

The isolated selected-SDK worker replays the actual private binary log, correlates `Csc` TaskInput events by submission/node/project/target/task context, and requires one successful build and one successful compiler task for the exact physical project. Required actual Sources, References and one OutputAssembly cannot be substituted with Workspace documents. Optional analyzers, additional files and analyzer configuration observations are retained only when actually present. Raw global properties and physical paths remain private transport. Completed builds hash the observed intermediate PE and matching PDB before the next context can overwrite them.

Inputs are capped at 64 MiB raw binlog, 200,000 decoded events, 32,768 retained input items and 2 MiB retained input characters. Private response transport is capped at 8 MiB and stdout/stderr at 4 KiB each. Cancellation and the owning process deadline bound replay; decode failures are typed refusals with no raw binlog diagnostics in public output. These are raw-file and retained-evidence limits, **not a decompressed-parser allocation bound**: MSBuild's reader may allocate a decoded record before the event callback. The worker is isolated and deadline-controlled, not OS-memory-limited. Complete owned build logs also consume disk; no whole-run disk cap is claimed.

The internal graph scheduler validates the entire loaded dependency-first graph and every Workspace association before its first build callback, freezes mapped globals/dependencies, and stops dependents on build failure. It requires a private resolved physical project path rather than confusing the stable logical project path with a local absolute path. Repeated contexts of the same physical project are conservatively refused until noncolliding destinations are independently proven, even where separate TFM outputs might be possible. The selected-SDK loader privately transports evaluated TargetPath and IntermediateOutputPath. Before any build callback the scheduler requires canonical, nonreparse destinations and rejects equal or ancestor/descendant output directories across nodes, including cross-role intermediate/final overlap. This conservative directory-level refusal also rejects shared directories with distinct assembly names; it is not filename-level scheduling. These are evaluated preflight destinations, not proof that custom targets preserve them during execution; actual compiler and final copied-output reconciliation remains mandatory. Real SDK integration covers a Release root with a mapped Debug dependency, target-added linked authored source, one actual build per node, and no implicit reference rebuild. Build counters explicitly exclude design-time target invocations; Workspace loading can invoke CoreCompile-related targets without an actual compiler build.

The Workspace loader also retains a private physical `CompilerDocuments` inventory before applying public generated-source exclusions. Ordinary SDK AssemblyInfo and assembly-attribute documents retain their resolved physical paths and byte hashes even when excluded from analysis. Target-added authored sources retain physical identities independently of `Link` names. Private worker transport preserves this inventory; ordinary public JSON, context identity, and capability flags do not change. Actual SDK integration compares the inventory with independently observed Csc Sources and reloads it after the build. This is a physical Workspace-document inventory, **not generator-only syntax-tree evidence**; source-generator proof/refusal remains a separate obligation.

Actual event association and immediate output hashing feed the phased binding used by public fresh orchestration. It checks original authored input stability, final generated/compiler membership, intermediate and copied PE/PDB/options, reference bytes/dependency copies and the final exact graph, retaining the proof for rechecks before and after required tests and before capture/publication. Actual Workspace-only generated trees are retained privately with exact UTF-8 bytes, encoding/preamble and SourceText checksum identity. They remain separate from physical Csc Sources and must each bind uniquely to a SHA-256 document in the accepted same-task PE/PDB module, under the existing PathMap and collision checks. Missing PDB documents (including declaration-only generated trees), ambiguous names or bytes, unsupported encodings and unproven generator loading/execution are refused; ordinary non-generator analyzer warnings alone do not invalidate project loading. Same-project contexts sharing outputs remain refused rather than being overwritten. A successful compiler task alone establishes neither successful tests nor reusable evidence. Custom output/PDB formats absent from this supported portable-PDB path fail explicitly. Raw binlogs may contain secrets despite ProjectImports=None and must never be exported in replay bundles or public artifacts. Invocation-owned directories must be private; Linux raw binlogs are chmod 0600 after the process completes, not an ACL guarantee during creation. Windows runtime validation remains mandatory.

The private context now carries role-bearing phase inputs (project/imports, prepared restore assets, physical authored/generated documents, SDK configuration, additional files, analyzer configuration and analyzer DLLs), plus a separate Workspace reference-path inventory. Missing analyzer configuration candidates exposed by Workspace are absence-bound probes, not nonexistent compiled inputs. None of these private paths are serialized into ordinary public context JSON or added to public context identity/capability claims. Workspace reference paths are not automatically interchangeable with actual Csc reference-assembly paths.

The internal `CompilerPhaseSnapshot` freezes every supplied graph binding's immutable input membership, roles, SHA-256 bytes, length and mtime before execution, and compares a final recaptured graph. It also binds absence of discovered analyzer-config probes. Byte changes with restored timestamps, timestamps alone, deletions, role/membership changes and authored-to-generated reclassification refuse. Only already classified physical generated source/configuration bytes are deferred to independent compiler/final binding; arbitrary project/import/assets/analyzer roles cannot be marked transitions. Static symlink ancestors and Linux special files are refused. Reads retain a fixed 64 KiB buffer and hashes, with 64 MiB/file, 512 MiB unique immutable closure and 32,768 role-bearing entries. These are accepted-input/retention limits, not hostile-filesystem atomicity or OS memory/disk bounds. Replacing a checked file concurrently is outside a sandbox guarantee. Actual SDK tests prove an ordinary generated build passes and a target mutation to an authored additional file refuses.

This snapshot is wired into the graph scheduler and public fresh check. It is one gate, not a substitute for final graph recapture/mapped selectors, independently observed Sources/References/optional inputs, complete generated-document binding, copied PE/PDB/options, reference closure or post-test rechecks. Reference paths are inventoried but not hashed by this authored snapshot: separate reference binding captures dependency outputs before dependent compilation and retains original reference bytes through tests, rather than treating references as generic generated transitions. Fresh binding can be verified while its safe capture remains nonreusable; neither snapshot nor compiler success supplies a complete future membership/environment recipe.

Supported graph binding is conservative. Dependencies must produce reference assemblies and observed runtime copies; `Private=false`/CopyLocal-disabled references and shared output layouts that omit those copies can refuse with `compiler.runtimeCopiesUnproven`. Disabling transitive project references can refuse `compiler.referencesUnproven` when the observed compiler closure differs from the staged dependency closure. These refusals never establish reusable success.

Authored test-child hook classification recognizes a finite set of built-in task names. It does not attest arbitrary custom task implementations with the same names; imported MSBuild logic requires a trusted repository. Independent post-test input/output proofs remain mandatory.

Generated output is captured using the existing generated source roles and remains part of the semantic compiler closure even when policy excludes it from scoring. No generated compiler path is opened as a file, inferred from a suffix, or adopted from a hash alone. An independently rerun generator driver remains a diagnostic only; accepted bytes originate in the actual Workspace compilation and must reproduce its SourceText checksum and the actual PDB SHA-256 checksum. Saved/prior validation reloads and compares that vector and preserves ordinary physical source, analyzer/configuration, currentness, reference, module and output checks. A map prefix omitted as inert for physical Csc sources must also be inert for every generated identity, or binding refuses. These changes add no public opt-out, report schema, policy relaxation or reusable authority.
